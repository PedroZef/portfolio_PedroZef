### 📌 Destaque

> Portfolio pessoal construído com **React 19 + Vite + TypeScript** e **CSS puro** (sem frameworks de estilo), com tema dark e dados centralizados em `src/data/*.ts`. O app vive na subpasta `portfolio_PedroZef/` do repositório de perfil [PedroZef/portfolio_PedroZef](https://github.com/PedroZef/PedroZef) — a raiz do repositório é o README do perfil, não o código do portfolio.

## Funcionalidades

- Tema dark com CSS puro, sem Tailwind
- 8 projetos na seção Projects
- 4 grupos de habilidades (IA, Front-end, Back-end e Ferramentas)
- 21 certificações com links para os arquivos em `certificados/` no repositório
- Formulário de contato via `mailto:` — sem backend
- TDD com Vitest + React Testing Library (9 testes em 7 arquivos)

## Tech Stack

| Tecnologia                     | Descrição                                                                        |
| ------------------------------ | ---------------------------------------------------------------------------------- |
| React 19                       | UI e componentes (Navbar, Hero, Projects, Skills, Certifications, Contact, Footer) |
| Vite                           | Build tool e dev server                                                            |
| TypeScript                     | Tipagem estática (`src/types.ts`)                                               |
| CSS puro                       | Estilização em`src/styles/global.css`                                          |
| Vitest + React Testing Library | Testes de componentes e integração                                               |
| Vercel                         | Deploy (Root Directory`portfolio_PedroZef`)                                      |

## Pré-requisitos

- **Node.js 20.19+ ou 22.12+** (requisito do Vite 8 — Node 22 LTS recomendado)
- **npm** (incluído na instalação do Node)

## Como rodar

### 1. Clonar o repositório

O app não fica na raiz do repositório, e sim em `portfolio_PedroZef/`:

```bash
git clone https://github.com/PedroZef/portfolio_PedroZef.git
cd PedroZef/portfolio_PedroZef
```

### 2. Instalar as dependências

```bash
npm install
```

### 3. Rodar em desenvolvimento

```bash
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) no navegador.

### 4. Rodar os testes

```bash
npm test
```

Executa o Vitest uma única vez (`vitest run`) e roda os 9 testes.

### 5. Build de produção

```bash
npm run build
```

Compila o TypeScript (`tsc -b`) e gera o bundle em `dist/`.

### 6. (Opcional) Preview do build

```bash
npm run preview
```

Serve o conteúdo de `dist/` localmente para você conferir o resultado final.

## Scripts disponíveis

## Como adicionar conteúdo

Todo o conteúdo fica nos arquivos de `src/data/` — não é preciso mexer nos componentes:

- **Projetos:** edite `src/data/projects.ts`
- **Habilidades:** edite `src/data/skills.ts`
- **Certificações:** edite `src/data/certifications.ts`

Para certificações, os arquivos (PDF, JPG, etc.) ficam na pasta `certificados/` na raiz do repositório e são referenciados pela base `https://github.com/PedroZef/portfolio_PedroZef/blob/main/certificados/<arquivo>`.

## Deploy na Vercel

1. Acesse [vercel.com](https://vercel.com) e faça login com sua conta GitHub
2. Clique em **Add New** → **Project**
3. Importe o repositório `PedroZef/portfolio_PedroZef`
4. Em **Root Directory**, selecione `portfolio_PedroZef`
5. Confirme o **Framework Preset** como `Vite` (detectado automaticamente)
6. Deixe Build Command (`npm run build`) e Output Directory (`dist`) como detectados
7. Clique em **Deploy**

O deploy fica disponível em: [https://portfolio_pedrozef.vercel.app](https://portfolio-pedrozef.vercel.app)
