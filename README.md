> Portfolio pessoal construido com **React 19 + Vite + TypeScript** e **CSS puro** (sem frameworks de estilo), com tema dark e dados centralizados em `src/data/*.ts`. O app vive na subpasta `portfolio_PedroZef/` do repositorio de perfil [PedroZef/PedroZef](https://github.com/PedroZef/PedroZef) — a raiz do repositorio e o README do perfil, nao o codigo do portfolio.

## Funcionalidades

- Tema dark com CSS puro, sem Tailwind
- 8 projetos na secao Projects
- 4 grupos de habilidades (IA, Front-end, Back-end e Ferramentas)
- 21 certificacoes com links para os arquivos em `certificados/` no repositorio
- Formulario de contato via `mailto:` — sem backend
- TDD com Vitest + React Testing Library (9 testes em 7 arquivos)
- Animacoes de entrada com CSS puro

## Tech Stack

| Tecnologia                   | Descricao                                                                          |
| ---------------------------- | ---------------------------------------------------------------------------------- |

## Pre-requisitos

- **Node.js 20.19+ ou 22.12+** (requisito do Vite 8 — Node 22 LTS recomendado)
- **npm** (incluido na instalacao do Node)

## Como rodar

### 1. Clonar o repositorio

O app nao fica na raiz do repositorio, e sim em `portfolio_PedroZef/`:

```bash
git clone https://github.com/PedroZef/portfolio_PedroZef.git
cd PedroZef/portfolio_PedroZef
```

### 2. Instalar as dependencias

```bash
npm install
```

### 3. Rodar em desenvolvimento

```bash
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) no navegador.

### 4. Rodar os testes

```bash
npm test
```

Executa o Vitest uma unica vez (`vitest run`) e roda os 9 testes.

### 5. Build de producao

```bash
npm run build
```

Compila o TypeScript (`tsc -b`) e gera o bundle em `dist/`.

### 6. (Opcional) Preview do build

```bash
npm run preview
```

Serve o conteudo de `dist/` localmente para voce conferir o resultado final.

## Como adicionar conteudo

Todo o conteudo fica nos arquivos de `src/data/` — nao e preciso mexer nos componentes:

- **Projetos:** edite `src/data/projects.ts`
- **Habilidades:** edite `src/data/skills.ts`
- **Certificacoes:** edite `src/data/certifications.ts`

Para certificacoes, os arquivos (PDF, JPG, etc.) ficam na pasta `certificados/` na raiz do repositorio e sao referenciados pela base `https://github.com/PedroZef/PedroZef/blob/main/certificados/<arquivo>`.

## Deploy na Vercel

1. Acesse [vercel.com](https://vercel.com) e faca login com sua conta GitHub
2. Clique em **Add New** > **Project**
3. Importe o repositorio `PedroZef/portfolio_PedroZef`
4. Em **Root Directory**, selecione `portfolio_PedroZef`
5. Confirme o **Framework Preset** como `Vite` (detectado automaticamente)
6. Deixe Build Command (`npm run build`) e Output Directory (`dist`) como detectados
7. Clique em **Deploy**

O deploy fica disponivel em: [https://portfolio-pedrozef.vercel.app](https://portfolio-pedrozef.vercel.app)
